# Not Human

* Explore a vast, decimated planet with **6 unique biomes**
* Discover **ancient civilizations**, **aliens** and their **tech**
* Use this knowledge to **terraform the planet**
  * Restore the atmosphere, wildlife and plants
* Defend against **alien threats** and **hostile creatures**

## Credit / History

This game was originally a Minecraft clone created by [paaracetamol](https://github.com/paaracetamol), who placed it in the [public domain](https://github.com/paaracetamol/kyklophobia).

It was forked on August 18th, 2026 and updated to be an independent game on alien survival and planet terraforming.
